# 🛠 Utility

| Command                        | Slash          | Description                                   |
| ------------------------------ | -------------- | --------------------------------------------- |
| **!bigemoji \<emoji>**         | **/bigemoji**  | enlarge an emoji                              |
| **!github \<username>**        | **/github**    | shows github statistics of a user             |
| **!help \[cmd]**               | **/help**      | help menu                                     |
| **!paste \<title> \<content>** | **/paste**     | paste something in sourceb.in                 |
| **!proxies \<type>**           | **/proxies**   | fetch various proxies (http, socks4 & socks5) |
| **!tr \<code> \<content>**     | **/translate** | translate from one language to other          |
| **!urban \<word>**             | **/urban**     | searches the urban dictionary                 |
| **!vc**                        | **/vc**        | control panel for your own voice channel      |
| **!weather \<place>**          | **/weather**   | get weather information                       |

### Reminders

- **/remind me in: about: \[dm] \[every]** — remind you later in this channel or by DM
- **/remind list** — your pending reminders
- **/remind cancel number:** — cancel one
- Prefix form: `!remind 2h check the deploy`, `!remind list`, `!remind cancel 1`

### Birthdays

- **/birthday set day: month: \[year]** — save your birthday
- **/birthday list** — upcoming birthdays of the server
- **/birthday config status:** — announcements (requires **Manage Server**)

### Polls

- **/poll create question: options:** — options separated by `|`, up to ten
- **/poll list**, **/poll close message_id:**

Full behaviour of all three: [Engagement & Community](../engagement.md).
